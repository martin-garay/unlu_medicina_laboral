### Validación automática obligatoria

- `git diff --check`;
- parseo de ambos inventories con `ansible-inventory --graph`;
- `ansible-playbook --syntax-check` para ambos inventories;
- ejecución exitosa de `validate.yml` para ambos inventories;
- prueba negativa: una versión PostgreSQL no soportada debe ser rechazada;
- `yamllint` y `ansible-lint` si están instalados.

### Validación manual sugerida

- revisar legibilidad de ambas guías;
- confirmar que ninguna variable secreta esté en texto plano;
- confirmar que cambiar una versión no implique modificar otra tecnología.

### Condiciones de stop

- un inventory no representa correctamente los grupos `app_servers` y `db_servers`;
- una selección no soportada pasa la validación;
- un archivo contiene credenciales reales;
- Ansible no puede parsear o ejecutar la estructura mínima.
